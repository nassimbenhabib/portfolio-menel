# Portfolio de Menel Bereksi

Le site est prêt pour GitHub Pages : index.html est à la racine.

1. Créer un dépôt sur le compte GitHub de Menel. Pour une adresse principale, le nommer exactement NOMUTILISATEUR.github.io, en remplaçant NOMUTILISATEUR par le véritable identifiant du compte.
2. Décompresser cette archive et importer son contenu à la racine du dépôt.
3. Dans Settings > Pages, choisir Deploy from a branch, puis main et / (root).
4. Utiliser l’adresse affichée par GitHub après la publication.

Les fichiers ne doivent pas être enfermés dans un dossier supplémentaire. La version française est dans index.html ; la version anglaise dans en/index.html. Les trois projets ont chacun une page dans chaque langue. La rubrique Formation est détaillée dans formation.html et en/formation.html. Les PDF, le portrait et les illustrations sont dans assets/. Les liens de contact utilisent un e-mail et LinkedIn ; aucune collecte de données n’est configurée.

Les textes s’appuient sur le CV de référence et sur le kit de contenus fourni en novembre 2026. La coupe P4 est une reconstitution des profondeurs consignées dans le carnet de terrain (p. 21 et 23) ; ses couleurs distinguent des intervalles de prélèvement et ne désignent pas des lithologies. Les pH et conductivités d’ENG31 et de l’exhaure sont des mesures de terrain consignées dans ce carnet. Les autres schémas restent conceptuels. Les exercices de modélisation sont identifiés comme des travaux universitaires ; aucune courbe analytique ni valeur de transmissivité non documentée n’est présentée. Le résumé EGU est une communication de congrès et n’est pas présenté comme un article de revue.
