# Portfolio de Menel Bereksi

Le site est prêt pour GitHub Pages : index.html est à la racine.

1. Créer un dépôt sur le compte GitHub de Menel. Pour une adresse principale, le nommer exactement NOMUTILISATEUR.github.io, en remplaçant NOMUTILISATEUR par le véritable identifiant du compte.
2. Décompresser cette archive et importer son contenu à la racine du dépôt.
3. Dans Settings > Pages, choisir Deploy from a branch, puis main et / (root).
4. Utiliser l’adresse affichée par GitHub après la publication.

Les fichiers ne doivent pas être enfermés dans un dossier supplémentaire. La version française est dans index.html ; la version anglaise dans en/index.html. Les trois projets ont chacun une page dans chaque langue. Les PDF et le portrait sont dans assets/. Les liens de contact utilisent un e-mail et LinkedIn ; aucune collecte de données n’est configurée.

Les textes sont fondés sur le CV français du 3 novembre 2026. Les illustrations sont conceptuelles et ne présentent pas de résultats mesurés. Le résumé EGU est une communication de congrès et n’est pas présenté comme un article de revue.
